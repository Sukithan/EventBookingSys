# Frontend Quick Start

## Installation

```bash
npm install
# or
yarn install
```

## Setup

```bash
cp .env.example .env
```

## Running

```bash
npm run dev
# or
yarn dev
```

Application available at: http://localhost:3000

## Pages

- `/` - Home page with tech stack overview
- `/items` - Items management (CRUD operations)
- `/about` - About the project

## Features

- Vuetify 3 components
- Tailwind CSS utilities
- TypeScript support
- Auto-imports
- API integration
- Responsive design

## Building for Production

```bash
npm run build
npm run preview
```
